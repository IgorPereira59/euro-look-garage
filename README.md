# 🚗 Euro-Look Garage

Projeto prático desenvolvido para a avaliação da disciplina de Front-End (Aulas 01 a 10) do curso de Análise e Desenvolvimento de Sistemas (Unipê). 

O projeto consiste numa Landing Page completa focada em customização e preparação automotiva, com ênfase na estética "Euro-Look" e otimização de motores GM Família II (Vectra GLS).

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação 100% semântica e boas práticas de acessibilidade.
* **CSS3:** Estilização global com Variáveis (`:root`), CSS Grid, Flexbox e design responsivo.
* **JavaScript (Vanilla):** Interatividade, manipulação do DOM e validação de formulários nativa.
* **Git & GitHub:** Controlo de versões e alojamento do repositório.
